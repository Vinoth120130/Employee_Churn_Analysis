# Employee Churn Analysis

This project analyzes HR data to identify factors behind employee attrition and build a model to predict churn risk. It was developed as part of the **Google Advanced Data Analytics Certificate** capstone.

## Goal

- Understand what drives employees to leave.
- Predict which employees are at risk of leaving.
- Provide insights to improve retention.

## Key Insights

- Low satisfaction and high workload increase churn.
- High-performing employees with many projects are more likely to leave.
- Low salary levels correlate with higher attrition.

## Tools & Techniques

- Python, Pandas, Numpy, Seaborn, Scikit-learn, XGBoost
- EDA, Chi-square test, Feature Engineering
- After Model Evaluation, the Random Forest model achieved AUC of 96.3%, precision of 98.4%, recall of 92.9%, f1-score of 95.6%, and accuracy of 98.6%, on the test set.
- The random forest modestly outperformed then decision tree model and XGBoost model

## Recommendations

- Improve employee satisfaction tracking.
- Manage workload to prevent burnout.
- Re-evaluate compensation strategy.
